# 北京房地产板块投资分析平台

基于北京真实地图展示板块、楼盘位置和项目去化数据的静态驾驶舱。

主要功能：

- 行政区划、板块、项目、成交月份和组团多选筛选
- 板块与楼盘地图定位、项目列表和单项目去化明细穿透
- 地图视图与 Excel 结构表格视图切换
- 多月份套数、金额、面积、均价、同比和环比合并计算
- 板块列表、项目详情全屏查看

## 数据更新

使用 Excel 工作簿更新页面数据：

```bash
python3 scripts/update_dashboard_from_xlsx.py "/path/to/北京各板块项目去化分析.xlsx"
```

脚本会保留页面中已经补齐的板块和楼盘经纬度，并更新项目月度去化指标、汇总指标、筛选月份和数据截止时间。
